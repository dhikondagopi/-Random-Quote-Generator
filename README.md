# 🎯 Random Quote Generator  

🚀 A simple and interactive web application that displays **random motivational quotes** using a free public API.  
Each time the user clicks the **"New Quote"** button, a fresh inspiring quote is fetched and displayed instantly.

---

## 📌 Project Overview  

The Random Quote Generator is a lightweight frontend project built to demonstrate **API integration, DOM manipulation, and responsive UI design** using core web technologies.

This project helps beginners understand how to fetch dynamic data from external sources and update the webpage in real time.

---

## ✨ Features  

✅ Fetches random motivational quotes from public API  
✅ Interactive "New Quote" button  
✅ Clean and responsive user interface  
✅ Fast loading and smooth user experience  
✅ Beginner-friendly project structure  

---

## 🧠 Technologies Used  

🌐 HTML5 – Page Structure  
🎨 CSS3 – Styling & Layout  
⚡ JavaScript – API Fetch & Dynamic Content
